``diffusion`` — Diffusion Operators
====================================

Pure, dimension-agnostic diffusion operators (constant- and
variable-coefficient Laplacians) and the :func:`~lilytorch.src.diffusion.diffuse`
forward-Euler increment, composed by
:class:`~lilytorch.src.advection.AdvDiffSolver`. This is the extension point
for future diffusion-model closures.
